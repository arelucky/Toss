# Toss App「静谧」视觉重设计

**日期：** 2026-08-25<br>
**状态：** 设计已确认，等待实施计划审核

## 目标

以已选定的「静谧（Stillness）」方向重做 iOS 用户端界面：克制、沉浸、有触感。Toss 仍是一场围绕单枚 3D 硬币展开的决策仪式；本次改造提升信息层级和视觉一致性，不改变 Toss、账户、下载或 Supabase 行为，唯一例外是已确认的「硬币库预选后确认应用」流程。

范围覆盖现有三处用户界面：

1. 首页抛硬币
2. 硬币库
3. 账户弹出页

管理后台不在本说明范围内，待 App 视觉方向实现后另行设计。

## 视觉系统

- **背景：** 接近纯黑的炭黑色，在硬币后方保留非常克制的暖色径向提亮。
- **文字：** 暖象牙白；次要内容使用降低透明度的象牙白，而非增加装饰性色彩。
- **强调色：** 香槟金只用于选中状态、主确认按钮和必要的交互强调。
- **尺寸：** 统一 8pt 间距节奏；所有可点击区域至少 44×44pt。
- **字体：** 使用系统无衬线字体建立层级；生产界面不使用装饰字体。
- **动效：** 继续以现有 3D 硬币、预览旋转、Toss、下载进度、声音与触觉作为唯一动态来源；不增加装饰性动画。

## 首页抛硬币

首页继续让选中的 3D 硬币成为唯一视觉焦点。

- 左上保留硬币库入口、右上保留账户入口；均为克制材质的 44pt 圆形按钮。
- 保留现有向上 Toss 手势与结果动画，不调整交互阈值或动画逻辑。
- 仅在空闲状态显示低调的向上手势提示；用户开始拖动、Toss 过程中或结果停留时自动淡出。
- 保留当前动态硬币模型来源、动态硬币原始材质、Classic 金色处理、缓存和拖动预览行为。

## 硬币库

硬币库继续采用全屏形式，保留现有 3D 主展示、拖动预览、WebP 缓存缩略图网格、动态下载进度和网络/失败处理。

- 保留居中紧凑标题和 44pt 返回按钮。
- 上方主展示显示当前**预选**硬币，并保留细香槟金选中环。
- 保留细分隔线与留白充足的双列圆形缩略图网格；不增加缩略图卡片背景、价格、锁、Premium 或付费元素。
- 下载、选中与加载提示统一使用细线与金色交互图标语言。
- 底部保留固定主按钮「Use This Coin」；它是应用选择并关闭硬币库的唯一动作。

### 选择状态流程

| 用户操作 | 硬币库状态 | 首页已应用硬币 |
| --- | --- | --- |
| 打开硬币库 | 当前已应用硬币成为预选项 | 不变 |
| 点击 Classic 或已缓存动态硬币 | 上方主展示和选中环更新 | 不变 |
| 点击未缓存动态硬币 | 启动现有下载并显示进度 | 不变 |
| 动态下载成功 | 下载完成的硬币自动成为预选项 | 不变 |
| 动态下载失败 | 保留当前预选项与既有错误提示 | 不变 |
| 点击可用状态下的「Use This Coin」 | 通过既有选择流程保存、登录后同步，并关闭硬币库 | 更新 |

只有预选硬币在本地可用时，主按钮才可点击。下载中或下载失败后按钮不可用；Classic 离线回退能力保持不变。

## 账户弹出页

账户继续以弹出页呈现，不改为新 Tab 或新页面。

- 保留 Guest、恢复中、已登录三种状态。
- 保留 Apple 登录、账户同步、声音与触觉设置、安全退出和删除账户确认流程。
- 将默认 `Form` 外观替换为与视觉系统一致的自定义深色分组布局：紧凑身份区域、清晰偏好设置组、明确分隔的危险操作。
- 不新增头像或资料编辑功能。登录态仍展示已有显示名；Guest 状态继续说明登录价值。
- 保留所有现有无障碍标签、确认弹窗和加载状态，仅调整样式。

## 架构与数据流

本次以视图层为主。既有 ViewModel、Repository、资源缓存、账户 Store 和 Supabase 合约保持不变。

- 仅在能减少三处界面重复时，引入小型可复用 SwiftUI 视觉组件或设计 Token。
- 状态所有权维持不变：`ContentView`、`CoinLibraryViewModel` 和 `AccountViewModel` 继续负责各自现有职责。
- 在硬币库 ViewModel 边界增加显式预选状态；用户点击底部确认按钮前，不持久化选择。
- 不修改 Storage、数据库 migration、Edge Function、动态资源下载链路或后台管理功能。

## 无障碍与异常处理

- 保持至少 44pt 点击区域、VoiceOver 标签、语义化按钮角色和适配动态字体的布局。
- 象牙白文字与深色表面保持高对比度；金色不作为唯一状态信息。
- 下载进度和失败提示沿用现有机制。
- 退出登录和删除账户继续要求现有确认步骤。

## 验证方式

实施时每个任务只运行聚焦 RED→GREEN 测试。最终在 iPhone15pm 完成人工验收：

1. 首页：选中模型、Toss 手势、动画、声音和触觉无回归。
2. 硬币库：预选不改变首页硬币；点击「Use This Coin」后才应用；Classic 和动态硬币的下载/选择状态正确。
3. 账户：Guest 与登录态布局可用；声音/触觉开关、退出和删除确认保持原行为。
4. 无障碍：顶部控制和硬币库主按钮均达到 44pt 且可被发现。

## 不在本次范围内

- 管理后台 UI 重设计
- 新增用户页面、Tab、导航、个人资料或社交功能
- StoreKit、价格、购买、订阅或付费权限
- 数据库、Storage、Edge Function 或 CDN 改动
- App 全面中文本地化；本任务保留现有英文文案，避免把样式改造与翻译混在一起
