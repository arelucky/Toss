# Toss 中国大陆发布架构设计

**日期：** 2026-08-31
**状态：** 已确认，待编写实施计划

## 目标

让 Toss 在中国大陆 App Store 正式发布，并为中国大陆用户提供稳定、合规的账户、硬币目录与资源下载体验；海外版保持现有行为与数据不受影响。

首发规模为 100–1,000 名用户。大陆版与海外版的账户和偏好数据完全独立。

## 已确认的产品边界

- 中国大陆与海外版均保留完整功能：可选 Apple 登录、账户删除、声音/触觉偏好同步和免费动态硬币下载。
- 当前版本已从中国大陆可用地区移除；备案与国内服务验收完成后才重新开启。
- 不迁移任何海外用户账户、偏好或登录会话至大陆环境。
- 不做首发双活、跨境账户同步或自动内容同步。
- 任何服务故障均不得影响内置 Classic 硬币和离线掷硬币体验。

## 环境选择

同一个 App Store App 在不同地区通常使用相同的 iOS 构建包，因此不能依赖不同地区上传不同固定服务地址的构建。

App 在首次启动时选择并持久化服务环境：

1. 读取 App Store 店面地区。
2. 中国大陆店面选择大陆环境；其他店面选择海外环境。
3. 若无法读取店面地区，仅在首次启动显示一次“大陆 / 其他地区”选择。
4. 选择保存后不因 VPN、网络 IP、旅行或临时网络变化自动切换。

环境选择必须在登录、目录加载和动态硬币下载之前完成。缓存以环境为命名空间，禁止大陆与海外模型、预览图或目录混用。

## 服务架构

```text
大陆版 Toss
  ├─ api.largemuscles.com
  │   └─ 阿里云中国内地 ECS 上的独立 Supabase
  │      ├─ Auth：Apple 登录
  │      ├─ PostgreSQL：账户、偏好、硬币目录
  │      ├─ Edge Functions：账户删除、管理员操作
  │      └─ REST API
  ├─ assets.largemuscles.com
  │   └─ 阿里云 OSS + CDN：USDZ 与 WEBP
  ├─ admin.largemuscles.com
  │   └─ 独立大陆管理员后台，仅连接国内 Supabase
  └─ toss.largemuscles.com
      └─ 支持与隐私页；迁入国内前维持现有 GitHub Pages

海外版 Toss
  └─ 保持现有 Supabase、对象存储与管理员后台
```

大陆首发使用一台具备备份策略的中国内地 ECS，不在首发阶段引入昂贵的双机高可用。所有外部访问均使用 HTTPS。App 只内置公开服务配置；Apple 服务端密钥、Supabase 服务端密钥和部署凭据只保存在阿里云服务端。

## 数据与内容初始化

大陆 Supabase 从当前迁移、RLS 和 Edge Function 定义初始化，但不导入海外用户表数据。初始内容仅包括：

- 当前发布的免费硬币目录、版本号、模型大小和 SHA-256。
- 与海外源文件逐字节一致的 USDZ 模型和 WEBP 预览图。
- 空的大陆账户、偏好和账户删除数据空间。

新硬币先由大陆管理员后台上传到大陆 OSS 并发布到大陆目录。海外与大陆内容在首发阶段人工对齐，不引入自动跨境复制。

## iOS 改动范围

- 将现有 `AppEnvironment` 扩展为可解析、持久化的地区环境。
- 由环境提供国内或海外的 API、认证和资源域名。
- 将目录、模型和预览图缓存隔离到环境命名空间。
- 保持掷硬币、RealityKit、动画、账户 UI、下载重试和后台业务接口的现有行为。
- 为店面识别、一次性回退选择、缓存隔离和默认离线回退新增单元测试与真机验收。

## 备案与发布

1. 采购并部署阿里云中国内地 ECS、OSS 与 CDN。
2. 为 API、资源和大陆后台绑定域名并配置 HTTPS。
3. 基于实际连接的国内服务域名、App 名称、图标、iOS 平台特征和第三方 SDK 信息提交 App 备案。
4. 如支持与隐私页迁入国内 OSS，完成该站点对应的网站备案并更新 `toss.largemuscles.com`。
5. App 备案成功后，在 App Store Connect 填写与备案信息一致的 ICP 备案号、名称和简体中文元数据。
6. 完成发布验收后重新开启中国大陆可用地区。

App 备案与网站备案彼此并列；已有网站备案不替代 App 备案。

## 验收与回退

验收：

- 中国大陆店面首次启动固定选择大陆环境。
- Apple 登录、登出、账户删除及偏好同步均在大陆环境可用。
- 目录、WebP 和 USDZ 请求只访问 `api.largemuscles.com` 或 `assets.largemuscles.com`。
- 离线或国内服务故障时，Classic 硬币可继续完整使用。
- 海外环境的请求、数据和体验无回归。
- 在大陆与海外环境分别完成真机测试，确认不存在跨环境请求。

回退：

- 重新关闭中国大陆 App Store 可用地区。
- 国内服务故障时保留 Classic 离线流程。
- 海外服务和海外用户数据不受任何大陆环境操作影响。

## 非目标

- 不进行海外与大陆账户同步。
- 不建立数据库双活或跨境内容自动同步。
- 不在首发阶段支持付费硬币、订阅或支付。
- 不修改当前已通过 TestFlight 验证的海外服务。
