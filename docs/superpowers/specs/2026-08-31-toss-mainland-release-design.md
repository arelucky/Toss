# Toss 中国大陆发布架构设计

**日期：** 2026-08-31
**状态：** 已确认，待修订实施计划

## 目标

让 Toss 在中国大陆 App Store 正式发布，并在不部署国内在线服务的前提下，为中国大陆用户提供完整、稳定的 Classic 离线掷硬币体验；海外版保持现有行为与数据不受影响。

中国大陆首发是成本受控的 Classic-only 产品档案。国内在线服务就绪后，以后续 App 版本恢复动态硬币和账户能力。

## 已确认的产品边界

- 中国大陆首发保留内置 Classic 硬币、掷硬币、声音与触觉设置。
- 中国大陆首发不显示也不初始化硬币库、动态硬币下载、账户登录、账户删除或云端偏好同步。
- 海外版维持可选 Apple 登录、账户删除、声音/触觉偏好同步和免费动态硬币下载的现有行为。
- 当前版本已从中国大陆可用地区移除；适用备案与 Classic-only 真机验收完成后才重新开启。
- 现有硬币库、账户、下载、管理员后台和海外数据代码均保留，不删除、不迁移。
- 不做首发大陆账号体系、双活、跨境账户同步或自动内容同步。
- 任何服务故障均不得影响内置 Classic 硬币和离线掷硬币体验。

## 环境选择

同一个 App Store App 在不同地区通常使用相同的 iOS 构建包，因此不能依赖不同地区上传不同固定服务地址的构建。产品能力同样必须由首次确定的地区档案控制。

App 在首次启动时选择并持久化地区档案：

1. 读取 App Store 店面地区。
2. 中国大陆店面选择 `mainlandClassicOnly`；其他店面选择现有海外完整档案。
3. 若无法读取店面地区，仅在首次启动显示一次“大陆 / 其他地区”选择。
4. 选择保存后不因 VPN、网络 IP、旅行或临时网络变化自动切换。

地区档案必须在任何在线依赖初始化之前完成。`mainlandClassicOnly` 不创建 Supabase 客户端、不读取目录、不创建模型/预览图下载器，也不建立任何在线缓存目录。未来国内服务恢复时，新增独立的大陆在线档案与缓存命名空间；不得复用海外会话、目录或模型缓存。

## 服务架构

```text
中国大陆首发 Toss
  ├─ 内置 TossCoin.usdz 与 ClassicCoinPreview
  ├─ 本地声音、触觉与设置
  └─ 不连接 Supabase、OSS、CDN、管理员后台或账户服务

toss.largemuscles.com
  └─ 现有支持与隐私页；作为产品支持页面独立维护

海外版 Toss
  └─ 保持现有 Supabase、对象存储与管理员后台
```

大陆首发不采购中国内地 ECS、OSS、CDN 或国内管理员后台。未来重新启用在线能力时，使用独立国内服务，所有外部访问均使用 HTTPS。App 只内置公开服务配置；Apple 服务端密钥、Supabase 服务端密钥和部署凭据只保存在服务端。

## 数据与内容

中国大陆首发不创建、读取或写入任何大陆账户、偏好、硬币目录、模型或预览图数据。用户的声音与触觉设置仅保存在设备本地。

未来恢复在线能力时：

- 建立独立大陆 Supabase、OSS/CDN 和管理员后台；不导入海外用户数据。
- 初始目录可人工复制当前发布的免费硬币，模型与预览图须验证大小与 SHA-256。
- 海外与大陆内容继续人工对齐，不引入自动跨境复制。

## iOS 改动范围

- 将现有地区解析扩展为可持久化的 `mainlandClassicOnly` 与海外完整档案。
- 大陆档案只装配离线掷硬币依赖，并从导航中移除硬币库和账户入口。
- 海外档案保留账户 UI、下载重试、硬币库、RealityKit 与后台业务接口的现有行为。
- 将大陆本地声音/触觉设置与海外云端偏好同步明确分开，保证用户不会看到失效入口。
- 为店面识别、一次性回退选择、在线依赖不初始化、入口隐藏与 Classic 离线回退新增单元测试和真机验收。

## 备案与发布

1. 根据实际大陆首发功能和接入信息，确认并完成适用的 App 备案要求；不得虚构国内服务器、后台或资源域名。
2. App 备案成功后，在 App Store Connect 填写与备案信息一致的 ICP 备案号、名称和简体中文元数据。
3. 完成 Classic-only 真机验收后重新开启中国大陆可用地区。
4. 将来建设国内在线服务前，重新进行服务接入、备案信息与 App 更新审核。

App 备案与网站备案彼此并列；已有网站备案不替代 App 备案。

## 验收与回退

验收：

- 中国大陆店面首次启动固定选择 `mainlandClassicOnly`。
- 中国大陆档案不显示硬币库或账户入口；应用启动与掷硬币不发起目录、认证、WebP 或 USDZ 网络请求。
- 声音、触觉与 Classic 硬币在无网络状态下完整可用。
- 海外环境的请求、数据和体验无回归。
- 在大陆与海外档案分别完成真机测试，确认大陆档案没有在线依赖。

回退：

- 重新关闭中国大陆 App Store 可用地区。
- 大陆首发无需服务回退；Classic 离线流程即为默认体验。
- 海外服务和海外用户数据不受任何大陆环境操作影响。

## 非目标

- 不在大陆首发部署 Supabase、OSS、CDN、国内管理员后台或任何替代性免费在线服务。
- 不进行海外与大陆账户同步，也不尝试将海外服务伪装成国内服务。
- 不建立数据库双活或跨境内容自动同步。
- 不在首发阶段支持付费硬币、订阅或支付。
- 不修改当前已通过 TestFlight 验证的海外服务。
