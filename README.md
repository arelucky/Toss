# Toss 🪙

## 项目简介

Toss 是一款使用 SwiftUI 开发的 iOS 极简掷硬币应用。

它不是一个普通的随机工具，而是一个具有仪式感的决策 App。

用户通过向上滑动抛出硬币，等待硬币在空中旋转，再通过「手掌覆盖手机」的方式揭晓最终结果，让每一次选择都充满期待。

---

## 产品理念

不是点击按钮得到答案。

而是完成一次属于自己的小仪式。

我们希望用户记住的是体验，而不是功能。
